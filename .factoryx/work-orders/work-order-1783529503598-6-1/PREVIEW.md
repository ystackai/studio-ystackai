# Preview — Bunny Orbit

- **Preview entrypoint**: `games/bunny-orbit/index.html`
- **Game type**: 3D browser game (Three.js, no build step)
- **How to play**: Open `games/bunny-orbit/index.html` in a browser. Click "Launch", then hold Space/click/tap to thrust toward the next planet. Release to drift. Reach the Carrot Moon to win.
- **Audio**: Foundry-generated music loop and SFX loaded via Web Audio API
- **3D protagonist**: Foundry-generated bunny astronaut GLB model loaded via GLTFLoader
